Main action button. Use one primary per screen (Oyna, Təsdiqlə, Qəbul et); secondary for parallel actions (Təhlil); danger only for Təslim ol / Klandan çıxar.
```jsx
<Button variant="primary" sub="0 / 2">Təsdiqlə</Button>
<Button variant="secondary" size="m">Təhlil</Button>
<Button variant="danger">Təslim ol · −1</Button>
```
Sizes: l=56 (in-game primary), m=48, s=40. `pressed` shows the 0.97 scale state.
